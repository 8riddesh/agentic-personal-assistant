# mobile - Flutter (Android only)

Specs: [`lib/features/*/spec.md`](lib/features). Global rules: [`../plan.md`](../plan.md) §2.2, §14.

## One-time setup (M0)

The Dart sources, `pubspec.yaml` and tests are committed. The **Android platform folder is generated by Flutter**
(it cannot be hand-written reliably), so run this once and commit the result:

```powershell
cd mobile
flutter create --platforms=android --org <your.reverse.domain> --project-name daily_assistant .
flutter pub get          # creates pubspec.lock - commit it
```

* `--org` + `daily_assistant` becomes the Android `applicationId` (e.g. `dev.riddesh.daily_assistant`). It is
  later registered as the Google OAuth client (calendar_connect), so pick it deliberately.
* `flutter create` keeps the existing `lib/main.dart`, `pubspec.yaml` and `test/` (it only adds missing files).
  If it did overwrite `lib/main.dart` or `test/widget_test.dart`, restore `lib/main.dart` from version control and
  delete `test/widget_test.dart` (the generated counter test no longer applies).

### Configure `android/` (app_shell spec §9, plan §14)

1. `android/app/build.gradle.kts` - set `minSdk = 26`, then add release signing that reads `key.properties`
   (git-ignored locally; written by `release-apk.yml` in CI):

   ```kotlin
   import java.util.Properties

   val keystoreProperties = Properties().apply {
       val f = rootProject.file("key.properties")
       if (f.exists()) f.inputStream().use { load(it) }
   }

   android {
       defaultConfig { minSdk = 26 }

       signingConfigs {
           create("release") {
               if (keystoreProperties.isNotEmpty()) {
                   keyAlias = keystoreProperties["keyAlias"] as String
                   keyPassword = keystoreProperties["keyPassword"] as String
                   storeFile = file(keystoreProperties["storeFile"] as String)   // relative to android/app
                   storePassword = keystoreProperties["storePassword"] as String
               }
           }
       }
       buildTypes {
           release {
               signingConfig = if (keystoreProperties.isNotEmpty()) signingConfigs.getByName("release")
                               else signingConfigs.getByName("debug")   // local `flutter run --release` still works
           }
       }
   }
   ```

   Locally, `android/key.properties` looks like:

   ```properties
   storePassword=...
   keyPassword=...
   keyAlias=release
   storeFile=../../../keys/daily-assistant.jks   # keep the keystore OUTSIDE the repo, and back it up
   ```

2. `android/app/src/main/AndroidManifest.xml` - add (release builds do not add it implicitly):

   ```xml
   <uses-permission android:name="android.permission.INTERNET"/>
   ```

   Do **not** set `usesCleartextTraffic` (HTTPS only). Notification permissions arrive with the notifications feature.

## Run / build

```powershell
# Debug on a connected phone (USB debugging on)
flutter run --dart-define=API_BASE_URL=https://<service>.onrender.com

# Debug APK (what mobile-ci builds)
flutter build apk --debug --dart-define=API_BASE_URL=https://<service>.onrender.com
adb install -r build\app\outputs\flutter-apk\app-debug.apk

# Signed release APK (needs android/key.properties)
flutter build apk --release --dart-define=API_BASE_URL=https://<service>.onrender.com
```

A build without `API_BASE_URL` shows a "Configuration error" screen (M-SHELL-AC-12).
